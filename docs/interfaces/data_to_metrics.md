# Interface: Data → Metrics

## Inputs
- Security identifiers
- Price histories
- Fundamental fields
- Metadata (sector, market cap, etc.)

## Outputs
- Clean, time-aligned numerical series
- Standardized identifiers
- Missing-data flags

## Assumptions
- Data is point-in-time consistent
- Survivorship bias handling is documented upstream

## Non-Responsibilities
- Metric interpretation
- Strategy evaluation
