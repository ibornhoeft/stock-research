# Data and Universe Definitions

## Initial Scope
- U.S.-listed common equities
- Excludes ADRs, OTC securities, and preferred shares

## Inclusion Rules
- Minimum market capitalization threshold
- Minimum liquidity threshold (average daily volume)

## Exclusion Rules
- Incomplete price history
- Corporate actions causing discontinuity (unresolved)

## Identifier Standard
- Primary: Ticker
- Secondary: CUSIP or internal ID

## Data Assumptions
- Prices are adjusted for splits and dividends
- Fundamental data is lagged appropriately

## Limitations
- Survivorship bias must be explicitly checked
- Point-in-time data quality varies by source
